# 功能与兼容性

DSH Claude Bridge 面向账号所有者本人使用，支持本人多台设备。使用边界和认证方式见 [首次使用](getting-started.md) 与 [服务器部署](remote-service.md)。

## 版本要求

| 组件 | 版本与要求 |
| --- | --- |
| 已验证支持的 DSH Desktop | 0.2.1-rc.5；加载时仍检查实际接口能力 |
| Claude Agent SDK | 服务器使用 0.3.314 |
| Claude Code | 服务器使用 2.1.314 |
| Node.js | 服务器为 24.9 或更高版本；Windows 更新器使用 DSH 自带运行时 |

目前围绕桌面端实际推送的 0.2.1-rc.5 维护。插件不按 DSH 版本号或安装文件摘要拒绝加载；缺少必要接口时会明确提示不兼容。结构或接口检查通过不等于行为完全兼容，不承诺所有旧版或未来版本都受支持。

桌面端推送新版后，再进行差异审查、针对性适配和核心回归。适配完成前，请继续使用上表列出的已验证版本。alpha 调研保留参考，不作为近期适配目标或发布门槛；服务器 SDK 和 CLI 不应静默升级。

### 验证范围

rc.5 已有的桌面和远程会话验证按下列功能与限制使用。补充的无密钥运行验证覆盖提示词送达、工具执行及续推理、工具结果落日志、历史回放和取消。它不能替代真实远程 SDK 全链路、审批界面、Electron／ASAR 桌面加载及 Windows 完整行为的对应实测，也不能据此宣称 alpha 已兼容。

插件读取安装版标准预设，但执行循环仍使用插件携带的 rc.5 派生代码，不会自动继承新版循环内部的行为。工具 Schema 转换也有支持范围。其他插件若依赖请求 hook、预设切换、计划、分叉或执行循环，需要分别核对兼容性。

### 远程会话的降级行为

单个高级工具无法转换时仅关闭该工具。可选预设组件无法加载或依赖尚未就绪时，会清理该组件的注册效果并显示原因；依赖未就绪时可在环境恢复后重载插件重新检查。

标准预设无法读取、适配，或完整预设的核心组件无法加载时，尝试插件自行维护的基础预设。基础预设保留身份、全局与项目指令、原生前台 shell，并尝试保留压缩及恢复命令；不启用子代理和后台任务。Windows 的最低 shell 为 PowerShell。

每轮请求及后续工具批次都会检查基础 shell 的可调用 Schema，以及审批、执行和结果记录接口。基础能力缺失或已确认执行器失效时，明确报告插件不可用并停止远程执行。正常命令非零退出、错误的单次工作目录、审批拒绝、超时和用户取消仍按原生结果处理，不等同于插件损坏；有副作用的调用不会自动重试。

模型工具列表、提示词、请求记录及设置页会同步反映禁用状态。降级限于远程预设，不更改普通 DSH 会话的工具注册。设置页同时列出当前桌面版本与已验证版本，尚未回归的桌面版本会显示提示。

## 支持的功能

| 功能 | 行为 |
| --- | --- |
| 专属远程会话 | 原生 SDK 保存真实模型上下文；DSH 管理本机会话和展示历史 |
| 模型与推理强度 | 使用账号实际返回的目录，可选择列表中显示的模型 |
| 文本与思考摘要 | 保存和展示正文；模型支持时显示官方思考摘要 |
| 文件与图片 | 使用 DSH 的本机读取、写入、编辑、搜索及权限；图片能力取决于所选模型 |
| 提问与审批 | 沿用 DSH 的用户提问、允许、拒绝和取消流程 |
| 指令与技能 | 在本机发现和去重，在工具批次边界送达新增上下文 |
| 停止 | 支持单项与整轮停止；停止不会撤销已经产生的副作用 |
| 上下文与压缩 | 展示 SDK 上下文近似快照，`/compact` 使用 SDK 原生压缩 |
| 自动压缩窗口 | 可跟随模型默认，或设置本设备全部远程会话共用的 100,000–1,000,000 tokens 窗口；从下一轮生效，不跨设备同步 |
| 订阅额度 | 底栏同时展示有效的 5 小时与周额度；仅返回一种时只显示该项，过期或账号未返回的数据不冒充为有效余额 |
| 本设备用量 | 展示本设备保存的 Token 用量与 SDK 费用估算，不是订阅账单 |
| 短断恢复 | 在恢复窗口内接回原工作进程，补齐及去重消息 |
| 崩溃后续聊 | 核对原生历史及已有工具回执，补齐记录后接受新输入 |
| 未知工具结果 | 保留未知状态并要求核实，不自动重跑有副作用的调用 |
| 多设备与并发 | 各设备独立身份与历史；不同会话可并行，同一会话串行 |
| 普通 DSH 子任务 | 新建独立会话，沿用父模型及 DSH 的深度限制 |
| 插件详情 | 包和组件显示名称、用途与内置图标，随 DSH 界面语言显示 |
| Windows 更新 | 支持在线一行命令和双击更新，自动识别安装位置并保留现有数据 |

## 恢复边界

客户端短断重连窗口为 60 秒，服务器保留原工作进程 90 秒。超过窗口、进程退出或资源上限后，转为历史核对；无法恢复已经消失的调用栈。

工具执行使用最终 SDK 参数。对于旧记录中 DSH 能证明尚未开始执行的调用，可以补正显示记录；已经执行或结果未知的参数冲突仍拒绝覆盖。

运行中补充的消息通过 SDK hook 上下文送达。模型对它的采纳可能有差异，需要中断当前行为时使用停止或拒绝审批。

## 当前限制

- 不支持会话分叉、`subagent_fork` 和计划模式。
- DSH 本机压缩关闭，真实模型上下文与压缩由 SDK 管理。
- 自定义压缩窗口需要新版服务器支持，不会扩大模型实际上下文；窗口大小和底栏上下文百分比是不同统计口径。
- 步骤及工具附加上下文只支持文本，不支持在这些位置附加图片。
- 服务器 SDK 只开放当前 DSH 声明的工具，不开放其原生 shell、文件工具或其他连接器。
- API Key 登录暂未开放；当前使用本人 claude.ai 订阅登录。
- 不提供跨设备历史自动同步、多租户隔离或账号级公平排队。
- 服务器默认 16 个连接槽位，不代表 16 路模型并发能力；复杂并发恢复和容量不作保证。

更新操作见 [保留数据更新](updating.md)，故障排查和诊断采集见 [性能诊断](performance.md)。
