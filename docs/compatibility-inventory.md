# 功能与兼容性

DSH Claude Bridge 面向账号所有者本人使用，支持本人多台设备。使用边界和认证方式见 [首次使用](getting-started.md) 与 [服务器部署](remote-service.md)。

## 版本要求

| 组件 | 版本与要求 |
| --- | --- |
| 当前适配的 DSH Desktop | 0.2.2-rc.1；保留 0.2.1-rc.5 回归，加载时仍检查实际接口能力 |
| Claude Agent SDK | 服务器使用 0.3.314 |
| Claude Code | 服务器使用 2.1.314 |
| Node.js | 服务器为 24.9 或更高版本；Windows 更新器使用 DSH 自带运行时 |

目前围绕桌面端实际推送的 0.2.2-rc.1 维护。插件按原生工厂和工具执行能力区分旧、新驱动，不按 DSH 版本号或安装文件摘要拒绝加载；缺少必要接口时会明确提示不兼容。结构或接口检查通过不等于行为完全兼容，不承诺所有旧版或未来版本都受支持。

启动时会在内存中构造合成会话，用安装版 DSH 的严格历史加载器检查工具调用、结果、轮次闭合及插件记录能否恢复；检查失败会阻止远程插件加载，不读取或修复已有会话。设置页的技术详情和诊断日志区分接口检查与合成行为探针，并明确标示桌面及真实 SDK 全链路未在本次启动自动验收；已验证桌面基线单独列出。

桌面端推送新版后，再进行差异审查、针对性适配和核心回归。适配完成前，请继续使用上表列出的已验证版本。alpha 调研保留参考，不作为近期适配目标或发布门槛；服务器 SDK 和 CLI 不应静默升级。

### 0.2.2-rc.1 适配

新版驱动保留原生 AgentModel、投影就绪、准备会话发布及恢复生命周期，只把远程推理步骤交给桥接。普通会话仍走安装版原生驱动；子代理使用当前安装版支持的选型与目录字段，恢复时不覆盖既有授权策略。

工具调用使用新版执行器的批次接口和每步准入，仍由原生策略处理审批、取消与超时，桥接保存自己的调用与结果记录。内部续步等本步工具结束后再关闭旧准入，附加上下文只投递一次。新版原生网页能力仅借用公开管道完成准备和权限检查，不在本机执行替代网页请求。

压缩完成卡片和旧进度记录展示随本次适配一起验证；新版的全部／最终回复折叠设置保持原生行为。脚本回归不代表桌面坐标点击或真实上游模型验收，具体检查口径见[桌面回归入口](rc5-regression.md)。

### 压缩记录与摘要

确认的 SDK 原生压缩通过 DSH 对话节点接口显示为折叠卡片，展开后展示原生摘要正文与实际报告的压缩前后 Token、耗时；缺失数值不估算。摘要仅保存在可忽略的展示记录中，不进入模型消息，不改动 SDK 上下文、原生恢复或 DSH 本机压缩检查点。

完整能力需要同时更新客户端插件与远程服务。握手分别声明实时摘要能力 `compactionSummaries` 和历史回补能力 `compactionHistory`；客户端只使用服务器实际声明的能力。旧服务器仍可连接，但不因此获得正文读取能力，已有压缩卡片会保留缺失说明。

实时正文来自 SDK 的 `PostCompact` Hook，并与已确认压缩边界可靠关联。原生文件中的历史摘要可能带有与 Hook 不同的续聊包装，因此优先使用有效 Hook 正文，不把两种来源的包装差异当作冲突。同一来源、同一边界出现不同正文时停止展示冲突正文；缺失、空白、无法对应和读取失败均保留明确状态。摘要正文上限为 1 MiB，传输时还受 RPC 报文预算限制；超过上限时报告不可用，不截断内容，也不另行请求模型生成摘要。

旧对话回补限于当前设备、DSH 对话、项目路径与 SDK 会话的既有绑定。服务器持有同一会话锁后，只读对应的单个原生记录文件，以原生边界 UUID 和摘要的明确父链接关联正文，不扫描无关会话或接受任意文件路径。文件指纹和分页游标用于复用未变化的读取结果；文件变化时重新核对并去重。读取不到原生证据时保留缺失状态，不用 DSH 历史伪造摘要。

已保存的旧压缩进度可以还原为卡片，重复采样不会生成多张相同卡片。已有边界 UUID 或已保存的明确对应关系优先；缺少标识时，只有同一绑定会话中两侧均唯一的触发方式和压缩前 Token 证据才能尝试对应，歧义时不向旧卡贴正文。没有可靠位置证据时追加标明“历史补录”的卡片，不冒充精确重建的位置。回补仅追加展示记录，不改写既有原始事件或服务器原生记录文件。

本轮隔离环境的 Haiku 5.5／low 原生手动压缩已收到 Hook 正文，并验证同边界原生文件历史正文回补、未变文件的空增量读取及压缩后续聊。未强制触发真实自动压缩；手动压缩、事件模拟和回放检查不替代真实自动压缩或长任务性能验证。

### 客户端与服务端版本协商

`serverVersion` 表示本桥接服务程序版本，`minimumClientVersion` 表示它要求的最低客户端插件版本；与 DSH Desktop、Claude Agent SDK 和 CLI 的版本分别管理。客户端与服务端版本无需相等，不能仅凭服务端版本更高判定客户端必须更新。

| 服务端声明 | 客户端行为 |
| --- | --- |
| 旧服务器未提供版本声明 | 新客户端按旧版兼容方式连接 |
| 提供服务端版本，最低客户端版本为 `null` 或未声明 | 继续连接，不额外强制更新客户端 |
| 声明有效的最低客户端版本 | 客户端达到或高于要求即可；低于要求或无法确认版本时，明确提示所需版本并阻止受保护操作 |
| 声明格式无效 | 明确报告无法确认兼容性，不假装支持 |

版本按 SemVer 比较，例如同一版本的 rc 早于正式版。v0.2.3 的服务器将 `remote/package.json` 中 `bridge.minimumClientVersion` 设为 `null`，本次升级兼容旧客户端。只有未来真正不兼容的更新才提高该最低要求，不为了对齐版本号强制升级。

这些声明及服务端操作门禁需要更新服务器代码后才可用；只更新客户端不会让旧服务器提供版本信息。旧客户端即使没有新增界面，遇到已提高的最低要求时，服务端仍会返回带所需版本的 `CLIENT_UPDATE_REQUIRED` 错误。无最低要求时不额外强制更新。

### 验证范围

rc.5 已有的桌面和远程会话验证按下列功能与限制使用。补充的无密钥运行验证覆盖提示词送达、工具执行及续推理、工具结果落日志、历史回放和取消。它不能替代真实远程 SDK 全链路、审批界面、Electron／ASAR 桌面加载及 Windows 完整行为的对应实测，也不能据此宣称 alpha 已兼容。

v0.2.9 让普通 DSH 会话使用安装版原生预设、`prepare` 和 driver，普通预设切换也委托原生规则；只有 Claude 远程会话使用专属预设和插件携带的兼容 driver。两类会话由同一个安装版原生工厂拥有，路由在 driver 构造前确定，不另建调度器。该路由随 v0.2.9 提供。

路由入口保留原生 `agent-loop` 的原始配置和表达式，源配置修改后需在空闲时重载入口。卸载整个工厂会收尾其拥有的普通与远程 Agent；恢复原生条目时继续使用原配置。远程兼容 driver 不会自动继承新版循环内部行为，工具 Schema 转换也有支持范围。其他插件若依赖远程请求 hook、预设切换、计划、分叉或执行循环，仍需分别核对兼容性。

远程指令仍由安装版原生组件发现、读取、去重和渲染。本插件只观察该组件实际发生的文件操作，并在最终请求边界核对来源与指令消息；超大来源、探测／读取失败、预算省略或来源未被实际上下文表示时，停止远程推理。可选文件缺失、空文件和原生同组去重不会当作遗漏；普通预设继续使用原生指令组件。

审计记录 `plugin:claude-bridge/instruction-audit` 只增加来源范围、摘要、字节数、版本是否可用及诊断结果，不另存指令正文。没有提供版本的来源明确记为未知；`prepared` 仅证明本机请求准备，不能作为 SDK 已消费确认。原生后台刷新失败会保留到对应远程会话的下一步检查，成功重读后解除；切换目录时跟随原生当前目录和有效来源。该检查不改变原生指令文本、SDK 绑定或系统提示摘要规则，也不替代真实 SDK 全链路验收。

### v0.2.9 更新范围：原生 SDK 标题与远程子代理选型

远程会话只同步 SDK 已有的自动／自定义标题，不另建标题对话、指定标题模型或思考强度。成功对话结束后读取一次 SDK 标题 metadata；尚无标题、读取失败或旧服务未返回时保留 DSH 兜底名称，下次正常对话可再次同步。DSH 手动改名优先；普通会话继续使用原生标题服务。SDK 自身的自动标题可能消耗辅助推理额度，生成策略由 SDK 管理，不保证首轮结束前一定获得标题。

原生 SDK 通常根据首次输入命名，不随随后话题反复改名；首条问候可能产生与 DSH 兜底相同的短标题。v0.2.10 在同名时也确认一次 SDK 来源，仍保留用户手动改名，不额外请求生成。

远程完整预设的子代理默认继承父模型与强度，也可显式选择当前 Claude 账号目录中的模型与支持的强度；`model-default` 明确清除继承的强度。原生运行时继续管理子会话、深度、取消和结果回传；普通会话与基础降级预设保持各自行为。

子代理选择范围由原生 Session 首次捕获并持久保存。缺少有效目录快照时只支持继承；尚未捕获策略的远程根会话可在刷新目录后重载 Agent。已有策略的会话不会因刷新扩充型号，新型号需要在刷新后新建远程根会话；旧父会话中的新子代理仍继承旧策略。执行前会实时核验型号与强度，旧列表不能放行已移除的选项。这些能力随 v0.2.9 提供。发布后用户已在新会话中观察到 SDK 原生标题生效；该例不等于所有标题完成时序或子代理显式选型子调用均已验收。

v0.2.10 的子代理列表只展示设置页勾选的型号。隐藏仅影响列表：显式指定当前账号目录中真实存在、且已被会话原生策略允许的型号，仍可调用；不存在的型号或不支持的强度明确报错，不替换为其他型号。全部取消勾选时列表为空，默认继承不变。既有会话的原生固定策略不因显示设置扩大；SDK 或上游内部的最终模型路由仍由其自身管理。

v0.2.10 在远程子代理输入区底部显示原生 `modelSelection.lastUsed` 中最近一次请求的型号／强度，完整页面与侧栏共用同一原生 dock 入口。名称只读取本机已加载目录；没有请求头时保持待确认，不使用父选型、待发送选择或模型自述代替。该标签表示已发出的请求配置，不冒称 SDK 实际解析型号回执。历史核对优先使用仍存活的真实子 Agent；冷子会话仅显示已有记录并返回只读状态，不创建替代 Agent 或假报同步成功，真实同步失败仍显示。

SDK 实际返回型号由独立的响应观察记录保存，只采用 `message_start.message.model` 或完整 assistant 的 `message.model`；型号提示仅在远程子代理页展示，主会话不增加常驻标签。新请求清除旧观察；新响应缺字段时保持未知，不沿用旧型号，也不从累计 `modelUsage` 或初始化信息推断。型号别名展开不等于降级；SDK 未报告实际思考等级时只保留请求等级。桥接不因此主动换型号或重试；未上报的上游内部路由无法确认，旧历史不补造证据。

### v0.2.6 更新范围

远程用量增加独立响应快照与整轮主代理总账，修复工具响应先提交、usage 后到时的漏计。累计增量按响应替换，不重复累加；底栏和轮末复用原生组件。旧对话继续读取，缺少可信明细的历史标注不完整，不伪造 Assistant attempt 或回填未经核对的数字。

普通 query 的自动压缩状态和数值边界进入展示；上下文 summary 在模型响应／工具批次后后台限频单飞采样，结束、取消与压缩代际隔离迟到结果。最终快照保持权威，采样失败保留旧值并提示。显示仍为带采样时间的近似快照，不保证逐 token 实时。

后续桌面适配新增压缩完成卡片，再通过独立的 Hook 与原生历史读取补充正文；边界事件本身不携带摘要。当前展示、旧记录回补与缺失处理见[压缩记录与摘要](#压缩记录与摘要)。

rc.5 定向回归覆盖严格日志回放、数值去重、压缩事件、旧状态、原生组件适配与卸载；一轮真实 Haiku 5.5／low、一次无副作用工具调用验证了运行中 summary 与后续工具批次和最终收尾。未强制大上下文触发真实自动压缩，也未补做完整桌面 GUI 或长任务提速基准。远端目录仅合并并发非刷新冷查询，不削弱执行前认证／模型／强度校验。SDK／CLI 固定版本及 `minimumClientVersion: null` 不变。

### v0.2.5 更新范围

本版支持基线仍为 rc.5。远程模型的两个选择入口共享按模型保存的本机强度偏好，普通模型的全局默认不变。正常定时同步静默，错误与待核实状态保留；上下文快照带有时间及模型／绑定信息，离线展示不代表可以离线执行。

启动模型列表使用按连接身份保存的展示目录，后台刷新失败会在远程设置模型区提示；执行前仍实时核验，不用展示缓存放行模型调用。安装版动态标准预设优先，自有等价完整声明只作兜底，再按下节规则隔离或回退基础能力。远程预设关闭新增原生时间上下文消息，普通 DSH 预设与已有 SDK 历史保留。

可识别的普通及 COMPACT 指令预算省略／截断标记会明确报错；原生超大源及读取失败的诊断尚未完整覆盖。系统提示变化仍安全停止，不伪造旧摘要或复制 DSH 历史重建 SDK 上下文；工具集合在同一 SDK 会话下一次 query 更新已有无密钥回归，不等同于运行中的 MCP 热切或真实 SDK 热更新验收。子代理模型／强度开放与缩小循环替换范围仍属后续工作。

独立 rc.5 配置已验证正式 v0.2.4 升级后保留历史、连接状态与 SDK 绑定，并以两次真实 Haiku 5.5／low、零工具调用确认旧上下文续聊及原生记录连续；提示词与工具指纹未变。另有隔离界面和无密钥回归覆盖强度记忆、离线展示及同步状态；这些结果不构成生产、全模型或未来插件热更新的通用承诺。本次服务端 `minimumClientVersion` 仍为 `null`，不因版本对齐强制旧客户端升级。

### 远程会话的降级行为

单个高级工具无法转换时仅关闭该工具。可选预设组件无法加载或依赖尚未就绪时，会清理该组件的注册效果并显示原因；依赖未就绪时可在环境恢复后重载插件重新检查。

标准预设无法读取或适配时，先尝试插件自行维护的等价完整声明；完整预设的核心组件仍无法加载时，再尝试基础预设。基础预设保留身份、全局与项目指令、原生前台 shell，并尝试保留压缩及恢复命令；不启用子代理和后台任务。Windows 的最低 shell 为 PowerShell。

每轮请求及后续工具批次都会检查基础 shell 的可调用 Schema，以及审批、执行和结果记录接口。基础能力缺失或已确认执行器失效时，明确报告插件不可用并停止远程执行。正常命令非零退出、错误的单次工作目录、审批拒绝、超时和用户取消仍按原生结果处理，不等同于插件损坏；有副作用的调用不会自动重试。

模型工具列表、提示词、请求记录及设置页会同步反映禁用状态。降级限于远程预设，不更改普通 DSH 会话的工具注册。设置页同时列出当前桌面版本与已验证版本，尚未回归的桌面版本会显示提示。

## 支持的功能

| 功能 | 行为 |
| --- | --- |
| 专属远程会话 | 原生 SDK 保存真实模型上下文；DSH 管理本机会话和展示历史 |
| 模型与推理强度 | 使用账号实际返回的目录，可选择列表中显示的模型 |
| 文本与思考摘要 | 保存和展示正文；模型支持时显示官方思考摘要 |
| 文件与图片 | 使用 DSH 的本机读取、写入、编辑、搜索及权限；图片能力取决于所选模型 |
| 提问与审批 | 沿用 DSH 的用户提问、允许、拒绝和取消流程 |
| 指令与技能 | 在本机发现和去重，在工具批次边界送达新增上下文 |
| 停止 | 支持单项与整轮停止；停止不会撤销已经产生的副作用 |
| 上下文与压缩 | 展示 SDK 上下文近似快照，`/compact` 使用 SDK 原生压缩；支持时以折叠卡片展示原生摘要并尽力回补旧记录 |
| 自动压缩窗口 | 可跟随模型默认，或设置本设备全部远程会话共用的 100,000–1,000,000 tokens 窗口；从下一轮生效，不跨设备同步 |
| 订阅额度 | 展示实际返回的 5 小时与周额度；v0.2.9 另保留标明“上次剩余”的历史缓存，过期或重置后的旧值不冒充当前余额，未返回的窗口不造数 |
| 本设备用量 | 展示本设备保存的 Token 用量与 SDK 费用估算，不是订阅账单 |
| 短断恢复 | 在恢复窗口内接回原工作进程，补齐及去重消息 |
| 崩溃后续聊 | 核对原生历史及已有工具回执，补齐记录后接受新输入 |
| 未知工具结果 | 保留未知状态并要求核实，不自动重跑有副作用的调用 |
| 多设备与并发 | 各设备独立身份与历史；不同会话可并行，同一会话串行 |
| 远程会话标题 | 同步 SDK 已有标题，保留手动改名，无独立标题推理或配置 |
| DSH 子任务 | 默认继承父选型；v0.2.9 允许远程完整预设选择同账号型号／强度，沿用原生深度限制 |
| 插件详情 | 包和组件显示名称、用途与内置图标，随 DSH 界面语言显示 |
| 桥接版本协商 | 展示服务端版本及最低客户端要求；未声明要求时保持兼容，需要更新时明确提示 |
| Windows 更新 | 支持在线一行命令和双击更新，自动识别安装位置并保留现有数据 |

## 恢复边界

客户端短断重连窗口为 60 秒，服务器保留原工作进程 90 秒。超过窗口、进程退出或资源上限后，转为历史核对；无法恢复已经消失的调用栈。

工具执行使用最终 SDK 参数。对于旧记录中 DSH 能证明尚未开始执行的调用，可以补正显示记录；已经执行或结果未知的参数冲突仍拒绝覆盖。

运行中补充的消息通过 SDK hook 上下文送达。模型对它的采纳可能有差异，需要中断当前行为时使用停止或拒绝审批。

## 当前限制

- 不支持会话分叉、`subagent_fork` 和计划模式。
- DSH 本机压缩关闭，真实模型上下文与压缩由 SDK 管理。
- 自定义压缩窗口需要新版服务器支持，不会扩大模型实际上下文；窗口大小和底栏上下文百分比是不同统计口径。
- 步骤及工具附加上下文只支持文本，不支持在这些位置附加图片。
- 服务器 SDK 只开放当前 DSH 声明的工具，不开放其原生 shell、文件工具或其他连接器。
- API Key 登录暂未开放；当前使用本人 claude.ai 订阅登录。
- 不提供跨设备历史自动同步、多租户隔离或账号级公平排队。
- 服务器默认 16 个连接槽位，不代表 16 路模型并发能力；复杂并发恢复和容量不作保证。

更新操作见 [保留数据更新](updating.md)，故障排查和诊断采集见 [性能诊断](performance.md)。
