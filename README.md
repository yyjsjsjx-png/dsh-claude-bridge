# DSH Claude Bridge

在本机 DSH 中使用远程官方 Claude Agent SDK：界面、历史、文件、命令、提问和审批留在本机，Claude 的原生会话、上下文和压缩由服务器上的 SDK 管理。

本项目是面向**个人账号、多设备自用**的实验性桥接，账号所有者的多台设备可以共用服务器地址和桥接口令。客户端不需要安装 Claude Code 或 Agent SDK。

**本项目由人工驱动的 vibe coding 完成。**

第一次使用请从 [首次使用与自部署指南](docs/getting-started.md) 开始；服务器安装与配置见 [远程服务部署](docs/remote-service.md)。公共源码不附带账号、服务地址或访问口令。

v0.1.5 移除了开发阶段遗留的每轮 0.15 美元费用估算上限。默认不设置额外的 SDK 美元预算；它与 Claude 订阅剩余额度无关。已有服务器须更新远端代码并重启服务，仅更新客户端不会改变服务器行为。

## 安装与连接

1. 安装 DSH。已有日常数据时使用独立配置和数据目录；全新测试虚拟机可直接使用新安装。
2. 在 **插件 → 添加插件** 中填入：

   ```text
   https://github.com/yyjsjsjx-png/dsh-claude-bridge#v0.1.5
   ```

   也可解压 Release 的插件 ZIP，添加其中**包含 package.json 的目录**。启用 bundle，按 DSH 提示重载。
3. 在 **设置 → 远程 Claude** 保存服务提供方给出的 **`wss://…` 服务器地址**和**独立桥接口令**，点击“测试连接并刷新模型”。公网 WSS 直接连接，不需要 SSH、密钥文件或额外启动脚本。
4. 在会话首页点击“新建远程 Claude”，选择账号实际返回的模型与推理强度，再开始对话。之后默认沿用上次成功选择；型号或强度不可用时回退为重新选择或模型默认强度。

已有安装可保留数据原地升级，无须还原快照。下载 [v0.1.5 插件 ZIP](https://github.com/yyjsjsjx-png/dsh-claude-bridge/releases/download/v0.1.5/dsh-claude-bridge-0.1.5.zip)，解压并完全退出 DSH，双击包根目录的 **`更新插件.cmd`**。结果窗口会保留，Windows 确实要求管理员权限时才请求 UAC。请保留解压目录。自定义路径、高级命令行、备份及失败处理见 [更新说明](docs/updating.md)。

设置页的“清除已保存连接”会关闭本机桥接连接，删除保存的服务器地址和桥接口令，清空未保存的口令草稿。会话历史、设备身份和服务器上的 Claude 登录保留；重新填写原连接后可继续原会话。执行任务或同步历史时需先等待结束。此操作不会撤销其他设备持有的同一口令。

如果服务器只提供回环入口，可选择 SSH 转发。标准内网端口为 `18944`；专用测试入口以提供方说明为准：

   ```sh
   ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=15 -o ServerAliveCountMax=3 \
     -L 127.0.0.1:18944:127.0.0.1:18944 your-user@your-server
   ```

转发建立后，服务器地址改填 `ws://127.0.0.1:18944/`。此地址通过 SSH 加密传输；公网明文 WebSocket 会被拒绝。

公开仓库和公开安装包不含服务器访问凭据。WSS 测试地址和口令由部署方单独提供；只有使用 SSH 方式时才需要连接脚本。

现有 DSH CLI 也可执行：

```sh
dsh plugin --profile your-test-profile add https://github.com/yyjsjsjx-png/dsh-claude-bridge#v0.1.5
```

## 已实现

- 本机 DSH 工具经结构化双向 RPC 提供给 SDK，保留原审批、提问、路径权限和取消。
- 文本、图片附件、本机路径读图、思考摘要、模型和 effort 目录；模型列表可自行筛选。
- 底栏精简上下文浮层、SDK 原生 `/compact`、5h 额度及明细浮层。周额度和专用额度仅在接口实际返回时显示。
- 额度前台每 60 秒检查，自动请求至少间隔 30 秒，轮末延迟 3 秒；隐藏、离线暂停。失败退避，鉴权失效暂停；过期数据不继续显示。
- 短断接回原 worker，按序补漏、确认和去重；本机工具等待连接恢复，离线停止优先。SSH 启动脚本只重建自己管理的转发。
- Host、worker 或服务崩溃后，从 SDK 原生记录补齐云端尾部，核对本机已保存结果及匹配的云端工具回执。界面显示恢复情况，用户可直接发下一条消息。
- 无法确认的工具结果保留为“待核实”，不重发原请求。下一条用户输入可附带已核实的恢复事实和只读核实建议，成功送达后去重，不额外发模型请求。
- 设置页打开时刷新本设备用量，前台每 5 秒更新，隐藏或离线暂停；兼容性和诊断明细默认收起。
- 停轮后的续聊沿用连续流式序号；原生回复以完整快照结算，精确过滤 CLI 的合成 `No response requested.` 占位。普通同文回复和其他错误保留。
- 当前会话轮末、恢复连接及重新可见时核对原生历史，前台空闲每 30 秒增量核对；升级后首次完整核对可修复旧版只保存尾部的展示。
- 历史补齐使用独立插件记录，保持原步骤位置和思考、正文顺序，不向已结束的原生轮次写消息；同一响应的工具只广告一次，累计展示不污染工具生命周期。跨页片段从响应起点重读。
- 启用时保留 DSH 原生会话控制器、预设注册器与客户端模块身份，策略在卸载时清理，避免热启用替换核心模块导致白屏。
- 远程模型和强度单独记忆，不再写入 DSH 普通新会话的全局默认。旧版遗留的远程默认会提示改走专用创建入口。
- 两端分段耗时、SDK 原始耗时字段、脱敏收集及性能报告。报告区分首 token 和首段正文，使用方式及虚拟机 agent 采集提示词见 [性能诊断](docs/performance.md)。

## 恢复边界

短断重连窗口为 60 秒，服务保留原 worker 90 秒；心跳、缓冲和历史同步均有容量与时间上限。Host、worker、服务重启后恢复原生记录和后续对话，不能恢复已经消失的进程调用栈，也不自动续跑未知副作用。

`/bridge-recovery` 可查看未知状态；用户核实后可用 `/bridge-recovery confirm` 解除后续运行门禁，原未知结果保持原样。停止不代表撤销已经产生的副作用。

会话分叉、`subagent_fork`、计划模式和 DSH 本机压缩保持关闭。步骤和工具附加上下文只接受文本。多设备各自拥有独立历史，device ID 不是多用户授权边界。

执行中追加的消息会在工具批次边界作为 SDK hook 的附加上下文送达。模型对这类消息的理解和响应存在差异，不能保证立刻回应或逐字复述；需要中止当前执行时，请使用停止按钮。模型自然结束一轮也不等于网络恢复失败，不会因此自动发起新一轮推理。

## 多设备与并发

同一服务地址和桥接口令可以供账号所有者自己的多台设备使用。各设备首次运行时生成独立 device ID；只复制连接地址和口令，不复制整个 DSH 数据目录。

| 场景 | 行为 |
| --- | --- |
| 多台设备 | 每台设备独立 worker 和会话绑定，可以同时使用；历史不自动跨设备共享 |
| 同一 Host 的多个窗口或会话 | 共享一条桥接连接；不同会话可并行，同一会话的运行和维护串行 |
| 普通 DSH 子代理 | 新建独立会话，继承父代理模型；可与其他会话并行，沿用 DSH 深度限制 |
| 同一 device ID 启动两个独立 Host | 已有连接仍活跃时拒绝后者；不允许两端抢写相同设备状态 |

普通新建子代理与会话分叉不同，`subagent_fork` 仍关闭。设备、窗口和子代理共享服务器资源与同一 Claude 账号额度，可能受到上游限流。多租户权限隔离不在本项目的验收范围。本版本没有账号级公平排队器；服务默认最多保留 16 个连接槽位（含短断保留项），这不是模型会话并发数保证。基础设备隔离、不同会话并行及同会话锁已有确定性测试；复杂并发父子崩溃恢复和容量压测尚未验收。

普通检查不安装 SDK。ASAR 专用检查使用已有 DSH Electron 的 Node 模式。`scripts/recovery-e2e.mjs` 使用实际 SSH、WebSocket、worker、DSH 持久化和本机工具进程，仅 SDK 是确定性替身；七类故障链路已通过，验收期间新增模型请求为 0。它需要现有独立测试服务器，运行方法见兼容清单。
